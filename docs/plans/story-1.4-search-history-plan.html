Chapter 1

The Mission

Scenario 1: history on focus

User has searched for several stocks. They click or focus the search field. A list of recent stocks appears below it, most recent at the top.

Scenario 2: straight to the card

Clicking a history row shows the stock card with current price and every metric. The preview list never appears.

Scenario 3: only 5

After many searches, the history shows the 5 most recent. Older entries drop off.

Out of scope!

No clear-history button, no per-row delete, no filtering history by typed text, no keyboard arrow navigation, no prices in the dropdown. These are not in the acceptance criteria.

Chapter 5

The Code

Pure core: utils/searchHistory.ts

export const SEARCH_HISTORY_LIMIT = 5;

export interface SearchHistoryEntry {
  symbol: string;
  companyName: string;
}

export function toSearchHistoryEntry(stock: StockData): SearchHistoryEntry {
  return { symbol: normalizeSymbol(stock.symbol), companyName: stock.companyName };
}

export function recordSearch(
  entries: SearchHistoryEntry[],
  entry: SearchHistoryEntry,
  limit = SEARCH_HISTORY_LIMIT,
): SearchHistoryEntry[] {
  const symbol = normalizeSymbol(entry.symbol);
  const rest = entries.filter((e) => normalizeSymbol(e.symbol) !== symbol);
  return [{ ...entry, symbol }, ...rest].slice(0, limit);
}

Refactor first: useLocalStorageState

export function useLocalStorageState<T>(
  key: string,
  parse: (raw: string | null) => T,
): [T, Dispatch<SetStateAction<T>>] {
  const [value, setValue] = useState<T>(() => parse(localStorage.getItem(key)));

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue];
}

Both stores keep the { items: [...] } envelope, so parseStoredItems(raw, guard) serves the watchlist and history. This keeps jscpd under 5%.

hooks/useSearchHistory.ts

const STORAGE_KEY = 'diamante.searchHistory.v1';

export function useSearchHistory(): SearchHistory {
  const [state, setState] = useLocalStorageState(STORAGE_KEY, parseHistory);

  const record = useCallback((stock: StockData): void => {
    setState((prev) => ({
      items: recordSearch(prev.items, toSearchHistoryEntry(stock)),
    }));
  }, [setState]);

  return { entries: state.items, record };
}

Functional update plus useCallback gives a stable record, so the effect deps stay honest.

StockSearch/useSearchHistoryDropdown.ts

export interface SearchHistoryView {
  entries: SearchHistoryEntry[];
  isOpen: boolean;
  onFocus: () => void;
  onBlur: () => void;
  onSelect: (entry: SearchHistoryEntry) => void;
}

export function useSearchHistoryDropdown(
  entries: SearchHistoryEntry[],
  query: string,
  loadSymbol: (symbol: string) => void,
): SearchHistoryView {
  const [isFocused, setIsFocused] = useState(false);
  const isOpen = isFocused && query.trim().length < 2 && entries.length > 0;

  function handleSelect(entry: SearchHistoryEntry): void {
    setIsFocused(false);
    loadSymbol(entry.symbol);
  }

  return { entries, isOpen, onFocus: () => setIsFocused(true),
    onBlur: () => setIsFocused(false), onSelect: handleSelect };
}

Chapter 6

The Villains

The Blur Bandit

Input onBlur fires before the row's onClick. The list unmounts and the click is lost.

Defeated by: onMouseDown → preventDefault() on each row button. An acceptance test clicks a row through userEvent, which fires the real event order.

Dr. Debounce

Any code that writes the symbol into query re-opens previews 400 ms later.

Defeated by: leaving the input unchanged. The Scenario 2 test advances time past the debounce and asserts no preview items exist.

The Duplicator

A second useWatchlist-style parse/persist block would push jscpd past 5%.

Defeated by: the refactor commit that adds useLocalStorageState and parseStoredItems before any history code.

The Prop Hydra

StockSearchPanel already takes 13 props. Five more hurt readability and line counts.

Defeated by: a single history: SearchHistoryView prop.

Length Lord

useStockSearchFlow is near the 40-line function limit.

Defeated by: keeping focus/open logic in useSearchHistoryDropdown. The flow only adds the record effect and loadFromHistory.

Corrupt Storage

Hand-edited or old localStorage data.

Defeated by: isSearchHistoryEntry guard. Bad rows are dropped, bad JSON gives [], and the list is sliced to 5 on read.
